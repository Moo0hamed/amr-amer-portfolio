# Amr Amer Studio

موقع بورتفوليو داخلي عربي/إنجليزي لـ **عمرو عامر** مبني على Next.js App Router وTypeScript.

## الحالة الحالية

- الواجهة العامة، RTL/LTR، اللغة العربية/الإنجليزية، الوضع الداكن، الأقسام التعريفية، الفلاتر، النموذج، وواجهة الاستوديو الخاص منفذة.
- تمت إضافة 50 صورة حقيقية من مجلد Google Drive العام، وكل بطاقة تفتح الملف الأصلي. الصور تمر عبر `/api/drive` لتفادي حجب تضمين صور Drive داخل المتصفح.
- روابط Behance وLinkedIn وInstagram وFacebook وWhatsApp والبريد مضافة كروابط فعلية.
- Owner Studio محمي بجلسة خادمية تعتمد على متغيرات البيئة، ولا توجد بيانات دخول افتراضية.
- نموذج التواصل يعرض حالة إعداد صريحة، ويدعم `CONTACT_WEBHOOK_URL` بعد تهيئته.
- رابط مجلد Google Drive العام محفوظ في بيانات الموقع، ولا توجد أسرار أو بيانات دخول ضمن الواجهة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

للفحص والبناء:

```bash
npm run typecheck
npm run lint
npm run build
```

## الإعداد اليدوي

1. انسخ `.env.example` إلى `.env.local`.
2. أنشئ `OWNER_EMAIL` و`OWNER_PASSWORD` و`OWNER_SESSION_SECRET` للوصول إلى `/studio`.
3. أضف `CONTACT_WEBHOOK_URL` إلى خدمة استقبال البريد/الرسائل إن أردت إرسال نموذج التواصل فعليًا.
4. لا يحتاج عرض الأعمال الحالي إلى OAuth؛ الملفات المستخدمة عامة ومقيدة بمعرّفاتها داخل مسار العرض الخادمي.

لا تضع أسرارًا حقيقية داخل الواجهة أو المستودع.
